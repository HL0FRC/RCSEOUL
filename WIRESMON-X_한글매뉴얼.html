1. WIRESMON-X 개요

WIRESMON-X란

WIRESMON-X(WIRES-X Remote Monitor)는 노드 PC가 있는 곳에 가지 않고도 인터넷을 통해 내 WIRES-X 노드를 감시하고 제어하는 YAESU의 Windows용 프로그램입니다. 무인으로 운용되는 노드의 상태를 확인하고, 문제가 생기면 송신을 막거나 소프트웨어를 다시 시작할 수 있습니다.

할 수 있는 일

기능내용
음성 모니터노드를 지나가는 양쪽 음성을 원격 PC 스피커로 청취
접속 상태 표시노드가 지금 어느 노드·룸에 연결되어 있는지, 송신·수신 중인지 표시
ON-AIR LOCK노드의 송신 금지(송신 차단)와 해제
소프트웨어 종료·재시작노드 PC의 WIRES-X 소프트웨어를 원격으로 종료 (자동 시작 설정 시 재시작)
웹 모니터웹 브라우저로 노드의 상태와 설정 정보 열람

구성

구분장소실행 프로그램
노드 PC무선국(HRI-200·무전기 설치 장소)WIRES-X 소프트웨어
원격 PC집·사무실 등 다른 장소WIRESMON-X.exe

두 PC는 인터넷으로 연결됩니다. 원격 PC는 노드의 DTMF ID · HRI-200 시리얼 번호 · 원격 제어 비밀번호 세 가지로 자기 노드를 찾아 접속합니다.

주의WIRESMON-X는 반드시 노드 PC가 아닌 다른 PC에 설치해야 합니다.

전체 진행 순서

  1. 노드 PC에서 원격 제어 기능을 켜고 비밀번호를 정한다 (3장)
  2. 원격 PC에 WIRESMON-X를 내려받아 압축을 푼다 (4장)
  3. WIRESMON-X를 실행해 접속 정보를 입력하고 연결한다 (5장)
  4. 상태 표시를 확인하고 필요한 제어를 한다 (6장, 7장)

버전 호환

  • WIRESMON-X Ver. 2.000은 IPv6 호환판 WIRES-X 소프트웨어만 제어할 수 있습니다.
  • WIRES-X 소프트웨어 Ver. 1.570 이전 버전은 제어할 수 없습니다. 노드 PC의 소프트웨어를 먼저 최신판으로 올려야 합니다.
  • 예전 원격 프로그램(Ver. 1.570 이전용, WiRES-II용 WIRESMON.exe)은 쓸 수 없습니다.
참고YAESU 원문은 접속 정보로 HRI-200 시리얼 번호를 요구합니다. HRI-200 없이 운용하는 노드(PDN 등)에서의 사용 가능 여부는 원문에 나와 있지 않으므로 별도 확인이 필요합니다.

3. 노드 PC 사전 설정

원격 접속을 하려면 노드 PC에서 먼저 아래 설정을 해 두어야 합니다. ①은 필수이고, ②·③은 해당 기능을 쓸 때만 필요합니다.

① 원격 제어 켜기와 비밀번호 설정 (필수)

  1. 노드 PC에서 WIRES-X 소프트웨어를 실행한다
  2. 메뉴에서 "File" → "Settings" 를 연다
  3. 왼쪽 "Property" 아래의 "General settings" 를 클릭한다
  4. "Remote control" 에 체크한다
  5. "Password" 에 원격 제어용 비밀번호를 입력한다
  6. [OK] 를 클릭한다
주의이 설정이 꺼져 있으면 WIRESMON-X에서 접속할 수 없습니다. 비밀번호는 노드를 제어할 수 있는 열쇠이므로 운용 책임자만 알고 있도록 관리하세요.

② 웹 모니터 설정 (웹 모니터를 쓸 때만)

플러그인 등록

  1. "Tool" 메뉴 → "Plugin set"
  2. [Add Module] 클릭
  3. "WiresWeb.dll" 선택 후 [Open] → 목록에 "WIRES WebServer" 표시
  4. [Close]
  5. "Tool" 메뉴 → "WIRES WebServer"
  6. 비밀번호와 포트 번호 확인 (비밀번호는 ①에서 등록한 값이 자동 입력됨)
  7. [OK]

포트 개방

  • 웹 모니터는 TCP 포트로 노드 PC와 통신합니다. 기본값은 46190 입니다.
  • 노드 쪽 공유기의 "NAT" 또는 "포트 매핑(포트 포워딩)"에 해당 TCP 포트를 등록하고, 내부 주소는 노드 PC의 고정 IP로 지정합니다.
  • 노드 PC의 방화벽에서도 WIRES-X 소프트웨어의 해당 포트 통신을 허용합니다.
참고웹 모니터를 쓰지 않고 음성 모니터·ON-AIR LOCK·재시작만 쓴다면 ②는 건너뛰어도 됩니다.

③ 자동 재시작 준비 (원격 재시작을 쓸 때만)

노드 PC에서 YMLAN.exe 의 Auto Start(자동 시작) 기능이 켜져 있어야, 원격에서 WIRES-X 소프트웨어를 종료했을 때 자동으로 다시 실행됩니다. 꺼져 있으면 종료만 되고 다시 켜지지 않습니다.

주의자동 시작이 꺼진 상태에서 원격 종료를 하면 노드가 멈춘 채로 남아 현장에 가서 직접 켜야 합니다. 원격 종료를 쓰기 전에 자동 시작 설정을 반드시 확인하세요. 설정 방법은 WIRES-X 소프트웨어의 도움말을 참조합니다.

4. 원격 PC에 설치하기

설치 프로그램이 따로 없고, 압축을 풀면 바로 실행할 수 있습니다.

내려받기와 압축 풀기

  1. WIRES-X 오너 페이지에 접속해 "Download WIRES-X Remote Control software" 를 클릭하고 화면 안내에 따른다
  2. wiresmon-x2000en.zip 파일을 원하는 폴더에 저장한다
  3. zip 파일을 마우스 오른쪽 버튼으로 클릭 → "압축 풀기" 를 선택해 원하는 폴더에 푼다 (예: C:\wiresmon-x)
  4. 필요하면 WIRESMON-X.EXE 를 오른쪽 클릭해 바탕화면 바로 가기를 만든다

들어 있는 파일

파일용도
WIRESMON-X.EXE실행 파일(본체)
DlgComFuncs.dll실행에 필요한 DLL
UdpComFuncs.dll실행에 필요한 DLL

주의EXE와 DLL 2개는 반드시 같은 폴더에 두어야 합니다. EXE만 따로 옮기면 실행되지 않습니다.

설정 파일 위치

처음 실행하면 접속 설정을 담은 WIRESMON-X.INI 파일이 문서 폴더의 \Documents\WIRESXA\ 아래에 자동으로 만들어집니다. 프로그램을 시작할 때 이 파일을 읽습니다.

삭제(제거)

압축을 풀어 생긴 파일들을 지우면 됩니다. 설정까지 지우려면 \Documents\WIRESXA\WIRESMON-X.INI 도 함께 삭제합니다.

5. 처음 실행과 접속

① 방화벽 허용

  1. WIRESMON-X.EXE 를 더블클릭해 실행한다
  2. 처음 실행하면 Windows 방화벽의 통신 차단 알림 창이 뜬다
  3. [액세스 허용] 을 클릭해 통신을 허용한다
참고알림을 실수로 닫았거나 차단했다면 Windows 설정 → 개인 정보 및 보안 → Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 에서 WIRESMON-X를 찾아 체크합니다. 별도 백신·보안 프로그램을 쓰면 그 프로그램에서도 허용해야 합니다.

② 접속 정보 입력 (Access Setting)

입력란입력할 값
DTMF ID내 노드의 DTMF ID 번호
Serial No노드의 HRI-200 인터페이스 박스 시리얼 번호
Password노드 PC에서 설정한 원격 제어 비밀번호 (3장 ①)
Save Password체크하면 비밀번호를 PC에 저장해 다음부터 다시 입력하지 않음
주의여러 사람이 쓰는 PC에서는 Save Password 를 체크하지 마세요. 그 PC를 쓰는 누구나 노드를 제어할 수 있게 됩니다.

③ 연결 (Connect)

  1. 노드 쪽 기기 전원이 켜져 있고 WIRES-X 소프트웨어가 실행 중인지 확인한다
  2. [Connect] 를 클릭한다
  3. 연결되면 화면에 노드의 User ID와 CallSign이 표시된다

연결이 안 될 때 나오는 메시지

메시지원인조치

Password Unmatch입력한 비밀번호가 노드에 설정된 비밀번호와 다름노드 PC의 General settings에 등록한 비밀번호 확인 후 다시 입력

④ 연결 끊기 (Disconnect)

원격 모니터링을 끝내려면 [Disconnect] 를 클릭합니다. 연결만 끊어질 뿐 노드 운용에는 영향이 없습니다.

7. 제어 기능 사용법

음성 모니터 (SOUND Monitor)

버튼을 클릭할 때마다 음성 모니터가 켜지고 꺼집니다. 켜면 노드를 지나가는 양쪽 음성을 들을 수 있습니다.

버튼 색상태
파란색모니터 중
회색모니터 꺼짐
주의음성 모니터는 노드가 NET(다른 노드·룸에 연결된) 상태일 때만 쓸 수 있습니다. IDLE 상태에서는 들리지 않습니다.

송신 제어 (ON-AIR ACTIVE / LOCK)

버튼을 클릭하면 노드의 송신 상태가 바뀝니다.

상태의미
ON-AIR ACTIVE정상 운용
ON-AIR LOCK송신 금지 — 노드가 전파를 내보내지 않음
참고LOCK을 걸었으면 원인 조치 후 반드시 ACTIVE로 되돌리세요. LOCK 상태로 두면 노드가 계속 송신하지 못합니다.

소프트웨어 종료·재시작 (App Quit)

노드 PC의 WIRES-X 소프트웨어에서 "File" → "Exit" 를 누른 것과 같은 동작을 원격으로 실행합니다.

  • 노드 PC에서 YMLAN.exe의 Auto Start가 켜져 있으면: 종료 후 자동으로 다시 실행 → 원격 재시작
  • Auto Start가 꺼져 있으면: 종료만 되고 노드가 멈춤 (3장 ③)

웹 모니터 (Web monitor)

  1. Web port 란에 노드 쪽 설정과 같은 TCP 포트 번호를 입력한다 (기본값 46190)
  2. [Web monitor] 버튼을 클릭한다
  3. 웹 브라우저가 열리고 노드의 상태와 설정 정보가 표시된다

노드 쪽에 플러그인 등록과 포트 개방이 되어 있어야 합니다 (3장 ②).

음량 조절 (Sound Volume Control)

  • 원격 PC에서 들리는 모니터 음량을 조절합니다. 노드 PC의 음량은 바뀌지 않습니다.
  • 이 조절은 Windows 볼륨 믹서의 "WIRES Monitor application Volume(응용 프로그램)" 항목과 연동됩니다.
  • 그래도 소리가 작거나 크면 Windows의 스피커(장치) 음량을 조절합니다.

창 닫기 (Close)

[Close] 를 클릭하면 창이 닫힙니다.

8. 상황별 사용 순서

평소 상태 점검

  1. WIRESMON-X 실행 → [Connect]
  2. User ID·CallSign이 내 노드가 맞는지 확인
  3. HRI-200 표시가 빨간색이 아닌지, RADIO 표시가 나오는지 확인
  4. IDLE / NET 과 연결된 노드·룸 ID가 의도한 상태인지 확인
  5. 필요하면 SOUND Monitor로 음성 품질 확인
  6. [Disconnect] 로 종료

노드가 계속 송신하거나 이상한 신호를 내보낼 때

  1. ON-AIR 표시가 녹색으로 계속 켜져 있는지 확인
  2. SOUND Monitor로 어떤 음성이 중계되는지 청취 (NET 상태일 때)
  3. 문제가 확인되면 [ON-AIR ACTIVE / LOCK] 버튼으로 ON-AIR LOCK 전환
  4. 원인 조치 후 다시 ON-AIR ACTIVE로 복귀

노드 소프트웨어가 멈춘 것 같을 때

  1. 표시가 갱신되지 않거나 상태가 비정상인지 확인
  2. 노드 PC의 자동 시작이 켜져 있는 것이 확실하면 [App Quit] 클릭
  3. 잠시 기다린 뒤 [Connect] 로 다시 접속해 정상 복귀 확인
  4. 다시 접속되지 않으면 현장 점검이 필요

10. 운용 시 주의사항

  • 비밀번호 관리: DTMF ID·시리얼 번호·비밀번호를 알면 누구나 노드의 송신을 막거나 소프트웨어를 끌 수 있습니다. 문서·메신저·공개 웹에 적어 두지 마세요.
  • 담당자 변경 시: 노드 PC에서 원격 제어 비밀번호를 바꿉니다.
  • LOCK 해제 확인: ON-AIR LOCK을 건 뒤에는 조치가 끝나면 ACTIVE로 되돌렸는지 꼭 확인합니다.
  • 원격 종료 전 확인: 자동 시작이 꺼진 노드에 App Quit을 쓰면 현장 출동이 필요해집니다.
  • 웹 모니터 포트: 포트를 열면 외부에서 접근 가능한 경로가 생깁니다. 쓰지 않으면 열지 않습니다.
  • 음성 모니터: 들은 교신 내용은 운용 점검 목적으로만 사용합니다.

11. 설정 점검표

노드 PC

확인항목
□WIRES-X 소프트웨어가 IPv6 호환 최신판이다
□File → Settings → General settings 의 "Remote control" 에 체크했다
□원격 제어 비밀번호를 설정했다
□(재시작 사용 시) YMLAN.exe Auto Start가 켜져 있다
□(웹 모니터 사용 시) WiresWeb.dll 플러그인을 등록했다
□(웹 모니터 사용 시) 공유기와 방화벽에서 TCP 포트를 열었다

원격 PC

확인항목
□Windows 11이고 노드 PC와 다른 PC다
□zip을 풀어 EXE와 DLL이 같은 폴더에 있다
□처음 실행 시 방화벽에서 통신을 허용했다
□DTMF ID·Serial No·Password를 입력했다
□Connect 후 내 노드의 User ID·CallSign이 표시된다
