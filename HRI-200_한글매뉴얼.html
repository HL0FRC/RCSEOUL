1. WIRES-X 개요

WIRES-X란

WIRES(Wide-coverage Internet Repeater Enhancement System)는 인터넷을 이용해 아마추어무선의 통신 범위를 넓혀 주는 시스템입니다. PC로 인터넷에 연결된 로컬 노드가 접속점(액세스 포인트) 역할을 하여, 이동국·고정국이 가까운 노드에 전파로 접속하면 전 세계의 무선국과 교신할 수 있습니다.

주요 특징

  • C4FM 디지털 통신 지원 — 음질 열화 없이 디지털 신호를 중계
  • 영문·숫자로 된 User ID 체계, ID 검색·접속 기능
  • 문자·사진·음성 데이터를 저장하고 읽는 뉴스 기능
  • 로컬 노드를 빨리 찾기 위한 프리셋 서치 채널
  • GM(그룹 모니터) 운용국의 신호 중계
  • DTMF 명령을 쓰는 FM 아날로그 통신 지원, 디지털국↔아날로그국 상호 교신 가능
  • HRI-200은 USB 한 가닥으로 PC와 연결·급전되며 USB 오디오 장치를 내장
  • 인터넷 포트 개방 상태를 점검하는 포트 체크 기능

교신이 이루어지는 흐름

  1. 아마추어국과 WIRES-X 노드를 개설한다
  2. 이동국·고정국이 노드를 찾는다
  3. 접속할 상대(노드/룸)를 지정해 연결한다
  4. 이동국·고정국이 음성을 송신한다
  5. 노드가 수신해 인터넷으로 상대 노드에 중계한다
  6. 상대 노드가 무전기로 재송신한다
  7. 상대 노드 채널을 수신 중인 무선국이 이를 듣는다

3. 사용 전 확인·안전 수칙

WIRES-X 소프트웨어는 최종 사용자 사용권 계약에 따라 구매자만 사용할 수 있으며, 사양·기능은 예고 없이 바뀔 수 있습니다.

위험

  • 병원·항공기 등 사용이 금지된 장소에서 쓰지 않는다 (전자·의료기기에 영향)
  • 가연성 가스가 있는 곳에서 쓰지 않는다 (화재·폭발 위험)

경고

  • 지정 전압 외의 전원을 쓰지 않는다
  • 분해·개조하지 않는다. 젖은 손으로 플러그·커넥터를 만지지 않는다
  • 연기·이상한 냄새가 나면 연결된 PC를 끄고 케이블을 뽑은 뒤 구입처나 YAESU 기술지원에 문의한다
  • 가습기 옆 등 물기가 닿기 쉬운 곳에 두지 않는다
  • 케이블을 무리하게 구부리거나 당기지 않고, 뽑을 때는 플러그를 잡는다
  • 케이블이 손상됐거나 커넥터가 꽉 끼워지지 않으면 사용하지 않는다
  • 금속 조각·물 등이 내부에 들어가지 않게 한다
  • 이어폰·헤드폰을 큰 음량으로 오래 쓰지 않는다
  • 천둥·번개가 칠 때는 PC를 끄고 전원 플러그를 뽑는다

주의

  • 난방기구 근처, 직사광선, 먼지·습기가 많은 곳에 두지 않는다
  • 신나·벤젠으로 닦지 않고 부드러운 마른 천을 쓴다
  • 장기간 쓰지 않을 때는 케이블을 뽑아 둔다
  • 던지거나 강한 충격을 주지 않는다. 위에 올라서거나 무거운 물건을 올리지 않는다
  • 자기 카드·테이프류를 가까이 두지 않는다. 어린이 손이 닿지 않게 한다
  • 케이블 위에 무거운 물건을 올리지 않는다
  • 라디오·TV 근처에서 쓰면 전파 간섭이 생길 수 있다
  • 지정 옵션 외의 제품을 쓰지 않는다. 불안정하거나 진동이 심한 곳에 두지 않는다
  • 케이스를 열지 않는다

4. 구성품·옵션·표기 규칙

구성품

  • HRI-200 본체
  • USB 케이블 (Type A – Type B)
  • CT-174: 미니 DIN 10핀–10핀 데이터 케이블
  • CT-175: 미니 DIN 10핀–6핀 데이터 케이블
  • WIRES-X 소프트웨어 설치 디스크(CD-R)
  • WIRES-X 사용자 등록 안내서

빠진 것이 있으면 구입처에 문의합니다. CT-174, CT-175는 옵션으로 추가 구매할 수 있습니다.

이 안내서의 표기

  • [GM], [Close] 처럼 대괄호 — 기기의 키·스위치 또는 PC 화면의 버튼
  • "Settings" 처럼 따옴표 — PC 화면의 제목·메뉴 항목 이름 (소프트웨어가 영문이므로 화면 표기는 영문 그대로 적었습니다)
  • OS 버전과 제품 업그레이드에 따라 실제 화면·명칭이 다를 수 있습니다

5. WIRES-X 서버 등록 (ID 발급)

참고다른 무선국이 개설한 공개 노드에 C4FM 디지털 무전기로 접속해 교신만 할 경우에는 서버 사용자 등록이 필요 없습니다.
  1. WIRES-X 웹사이트 접속: https://www.yaesu.com/jp/en/wires-x/index.php
  2. "New Member Registration" 클릭
  3. 이메일 주소를 입력해 제출 → 회원 등록용 주소가 담긴 메일이 옵니다
  4. 해당 주소로 들어가 "Apply for WIRES-X new ID (membership registration)" 선택
  5. 사용권 계약 화면에서 [I Agree] 클릭
  6. 필수 항목을 입력해 제출 → 완료되면 ID 취득 안내 메일이 옵니다
참고무전기 시리얼 번호는 등록할 필요가 없습니다. FTX-1은 HRI-200을 쓰지 않으므로 FTX-1의 "RADIO ID"를 입력합니다. 등록 처리에는 영업일 기준 4~5일이 걸립니다.
주의기술 발전이나 규제 변화로 서버 운영이 어렵다고 YAESU가 판단하면 WIRES 서버 운영이 중단될 수 있습니다.

WIRES-X 소프트웨어 설치

  1. CD-R의 "Install.exe" 실행
  2. [WIRES-X Software Setup] 클릭 → 설치 마법사 시작
  3. [Next] 클릭
  4. 사용권 동의 체크박스에 체크 후 [Next] (체크하지 않으면 설치 중단)

    "Enable WIRES-X Auto Start."에 체크하면 Windows 시작 시 자동 실행되고, 프로그램이 종료돼도 자동으로 다시 실행됩니다
  6. [Install] 클릭 (설정을 바꾸려면 [Back], 그만두려면 [Cancel])
  7. [Finish] 클릭 → 바탕화면에 Wires-X 아이콘 생성
  8. "WIRES-X installer" 창에서 [Close]

HRI-200과 PC 연결

중요USB 드라이버 설치가 끝나기 전에는 HRI-200을 PC에 연결하지 마세요. 먼저 연결하면 오동작할 수 있습니다.
  • 부속 USB 케이블로 HRI-200(Type B)과 PC(Type A)를 연결하고, PC는 LAN 케이블로 인터넷에 연결합니다
  • 정상 연결되면 PC를 켤 때 HRI-200도 자동으로 켜집니다
  • 공유기 사용 시 배선과 초기 설정은 공유기 설명서를 따릅니다 (보통 웹 브라우저로 공유기 IP에 접속해 설정)
  • FTX-1은 별매 USB Type-C 케이블로 PC에 직접 연결합니다

페라이트 코어

고주파 잡음을 줄이기 위해 USB 케이블 양쪽 끝을 부속 페라이트 코어에 한 바퀴 감은 뒤 코어를 닫습니다. USB 플러그에 최대한 가깝게 답니다.

주의케이블 연결 전에 무전기 전원을 끄세요. 무전기용 DC 13.8V 전원은 별도로 준비합니다.

8. 인터넷 환경 준비

먼저 확인WIRES-X 소프트웨어 Ver. 2.000은 포트 개방이 필요 없습니다. Ver. 1.570 이전 노드가 접속할 수 있는 구버전 호환 룸을 열 때만 아래의 포트 개방·고정 IP 설정이 필요합니다.

왜 설정이 필요한가

  • 포트 개방: Ver. 1.570 이전 노드·룸은 UDP 포트 46114, 46120, 46122로 통신합니다. 시판 공유기는 기본값에서 이 통신을 막으므로 포트를 열어야 합니다
  • 고정 IP 지정: 공유기의 DHCP는 PC를 켤 때마다 다른 IP를 줄 수 있습니다. 포트 개방은 대상 PC를 IP로 지정하므로, 노드 PC의 IP를 고정하고 그 주소를 공유기에 등록해야 합니다

PC에 고정 IP 설정 (Windows 11)

  1. 화면 오른쪽 아래 네트워크 아이콘을 오른쪽 클릭
  2. [Network and Internet settings] 클릭
  3. [Ethernet] 클릭
  4. "IP assignment" 항목의 [Edit] 클릭
  5. [Manual] 선택
  6. [IPv4] 켜기
  7. IP 주소 입력
  8. 서브넷 마스크에 255.255.255.0 입력
  9. 기본 게이트웨이에 공유기 IP 입력
  10. 기본 DNS 서버에 공유기 IP 입력
  11. [Save] 클릭
참고IP 주소의 마지막 자리는 공유기가 허용하는 범위 안에서 정합니다(공유기 설정 화면 참조). 공유기에 여러 기기를 연결할 때는 IP가 겹치지 않게 합니다.

공유기 포트 개방

공유기에 UPnP 기능이 있으면 WIRES-X 소프트웨어에서 포트를 열 수 있고, 없으면 공유기 설정 화면에서 직접 엽니다. UPnP가 있어도 소프트웨어로 열리지 않으면 공유기 화면에서 엽니다.

UPnP가 없는 공유기

공유기의 "NAT" 또는 "포트 매핑(포트 포워딩)" 설정에서 LAN 쪽 주소를 노드 PC의 고정 IP로 지정하고 UDP 46114, 46120, 46122 3개를 등록합니다.

UPnP가 있는 공유기

  1. 공유기 설정 화면에서 UPnP가 켜져 있는지 확인
  2. 바탕화면의 Wires-X 아이콘을 더블클릭해 실행
  3. 인터넷 보안 경고가 나오면 [Allow access](환경에 따라 [Unblock]) 클릭 → "WIRES ID Activation" 창 표시
  4. [Port check] 클릭
  5. "Port Check" 영역의 "Automatic UPnP"에 체크
  6. [Start] 클릭 → 6개 포트의 통신 상태를 점검해 포트별로 OK / NG 표시. NG가 하나라도 있으면 3개 포트 등록을 자동으로 시도한 뒤 다시 점검
  7. 모든 포트가 OK이면 [Close]
주의다시 점검해도 NG가 남으면 소프트웨어로는 포트를 열 수 없는 환경입니다. 공유기 설정 화면에서 직접 엽니다.
참고원격 모니터 기능으로 노드를 원격 제어하려면 TCP 포트 46190(기본값)을 열어야 합니다 (17장).

  • 특정 그룹만 쓰는 노드는 DG-ID를 00 이외로 정하고, 그룹 무전기 모두를 같은 번호로 맞춥니다

14. 프리셋 서치 채널

개념

이동국·고정국이 WIRES-X 노드를 찾을 때 쓰는 미리 약속된 채널입니다. 이 주파수를 무전기에 등록해 두면 가까운 노드를 빨리 찾을 수 있고, 평소와 다른 장소에서도 근처 노드를 찾을 수 있습니다.

주의C4FM 디지털 통신에서만 동작하며, HRI-200으로만 설정할 수 있습니다.

운용 방식 2가지

방식연결동작
무전기 1대C4FM 무전기를 RADIO 1에 연결대기 중에는 프리셋 서치 채널과 음성 채널을 번갈아 감시. 다른 노드·룸에 접속하면 프리셋 채널 감시를 멈추고 음성 채널만 송수신
무전기 2대음성 채널용을 RADIO 1, 프리셋 서치 채널용을 RADIO 2에 연결두 채널을 항상 수신 대기. 프리셋 채널로 신호가 오면 음성 채널 정보를 보낸 무선국에 전송. 접속 중에도 프리셋 채널 감시 지속

설정

"Transceiver" 창에서 "RX:DIGITAL - TX:DIGITAL"을 선택한 뒤, "Operation mode"를 1대 운용이면 "Dual Rcv", 2대 운용이면 "ON"으로 합니다.

참고DR-2X/DR-1X 리피터에 연결하는 경우는 해당 기종용 HRI-200 참조 매뉴얼을 봅니다.

15. 룸(Round QSO Room) 개설·운영

룸이란

여러 노드와 무선국이 동시에 접속해 자유롭게 대화하는 WIRES 상의 공용 공간입니다. 누구나 들어오는 오픈 룸과 등록 회원만 접속하는 클로즈드 룸이 있습니다. 룸은 노드 소유자가 개설하며 관리 책임도 소유자에게 있습니다. 노드 1개당 룸 1개를 열 수 있습니다. 로컬 노드가 룸에 들어가면 그 노드에 접속한 무선국도 함께 룸에 들어갑니다.

룸 열기

서버에 등록하면 노드 ID와 함께 룸 ID도 발급됩니다. 노드를 개설했다면 별도 장비 없이 룸을 열 수 있습니다.

  1. WIRES-X 소프트웨어 실행
  2. "File" → "Settings"
  3. "Round QSO room settings" 클릭
  4. [Setup] 클릭 → "Room Open" 창
  5. "Room Active"에 체크
  6. [Room Activation] 클릭 → 서버에 전송·확인되면 룸 활성화
  7. [OK]

16. GM(그룹 모니터) 기능

GM 기능이란

같은 주파수에서 GM 기능을 쓰는 무선국이 교신권 안에 있는지 자동으로 확인하는 기능입니다. 자주 교신하는 무선국을 그룹으로 저장해 두면 메시지·사진 송수신, 회원의 교신권 진입 알림, 위치 정보 활용이 편리합니다.

WIRES-X 디지털 노드에서도 GM을 쓸 수 있습니다. 노드가 그룹 회원이면 이동국에서 노드 운용 상태(WIRES-X 사용 가능 여부)를 확인할 수 있고, GM 노드끼리 WIRES-X로 연결되면 교신권과 관계없이 그룹 회원과 통신할 수 있습니다.

GM 지원 기종: FTM-510D/500D/400XD/400D/310D/300D/200D/100D, FT5D, FT3D, FT2D, FT1XD/FT1D, FT-70D, FTX-1

운용 전 준비

  • 노드용 무전기는 HRI-200 모드 호환 C4FM 기종(FTM-510D/500D/400XD/400D/310D/300D/200D/100D, 2026년 2월 기준)
  • 무전기 1대만 사용 — GM 운용 중에는 프리셋 서치 채널을 쓸 수 없으므로 RADIO 1에만 연결
  • 넓은 범위의 회원과 통신하려면 GM 전용 룸을 준비. 회원이 될 노드가 룸을 열고 이동국·고정국·노드를 회원으로 등록

GM 노드로 운용 시작

  1. WIRES-X 소프트웨어 실행
  2. 메인 화면 오른쪽 아래 [GM] 클릭 → "GM (Group Monitor) Guide" 창
  3. [Transceiver] 클릭
  4. "Voice CH"에서 "RX:DIGITAL - TX:DIGITAL" 선택
  5. [OK]
  6. [Node Operation] 클릭 → "User ID Change" 창
  7. "Style"에서 "GM" 선택
  8. [Apply] → [OK]
  9. [Close] → GM 노드로 동작 시작

GM 룸에 접속·회원 추가

  1. [GM] 클릭 → GM Guide 창
  2. [GM Room select] 클릭 → "GM Room list" 창 ("View" → "Node-Info" → [Select change]로도 열림)
  3. GM Group List 영역을 클릭해 추가 시작
  4. "Room ID"에 접속할 GM 룸 ID 입력 → 서버에서 DTMF ID와 룸 이름을 자동으로 불러옴
  5. "Group Name"에 원하는 이름 입력
  6. [Replace] 클릭 → 목록에 추가 (여러 개면 4~6 반복, "Comment"에 메모 가능)
  7. 목록에서 접속할 GM 룸 선택
  8. [Select] 클릭 → 접속 시작
  9. [Mobile User list] 클릭
  10. 회원으로 넣을 이동국 선택
  11. [Add GM member] 클릭 → 현재 접속 중인 GM 룸의 회원으로 추가
  12. [Close]

17. 원격 운용 (리모트 모니터)

다른 PC에서 인터넷을 통해 WIRES-X 소프트웨어를 조작할 수 있습니다.

할 수 있는 일

  • 음성 모니터: 노드가 접속 중일 때 중계되는 음성 청취
  • PTT 제어: 노드 송수신 정지(ON-AIR LOCK)와 해제(UNLOCK)
  • 소프트웨어 재시작
  • 웹 모니터: 웹 브라우저로 운용 상태와 설정 확인

준비

  • 노드 PC와 별도로 인터넷에 연결된 원격 조작용 PC (노드 PC와 동등한 사양 권장)
  • 전용 소프트웨어 내려받기: WIRES-X 오너 페이지에서 "Download WIRES-X Remote Control software" 클릭 후 화면 안내에 따름
주의WIRES-X 소프트웨어 Ver. 2.000 전용 원격 소프트웨어가 필요합니다. Ver. 1.570 이전용이나 WiRES-II용 "WIRESMON.exe"는 쓸 수 없습니다.

사전 설정

① 포트 개방

웹 모니터 기능은 TCP 포트 46190으로 노드 PC와 통신합니다. 공유기의 "NAT" 또는 "포트 매핑"에 TCP 46190을 등록하고 LAN 쪽 주소는 노드 PC의 고정 IP로 지정합니다.

② 소프트웨어 설정

  1. WIRES-X 소프트웨어 실행
  2. "File" → "Settings"
  3. "Property" 아래 "General settings" 클릭
  4. "Remote control"에 체크
  5. "Password"에 새 비밀번호 입력
  6. [OK]

③ 전용 플러그인 등록 (웹 모니터용)

  1. "Tool" 메뉴 → "Plugin set"
  2. [Add Module] 클릭
  3. "WiresWeb.dll" 선택 후 [Open] → 목록에 "WIRES WebServer" 표시
  4. [Close]
  5. "Tool" 메뉴 → "WIRES WebServer"
  6. 비밀번호와 포트 번호 확인 (비밀번호는 ②에서 등록한 값이 자동 입력됨)
  7. [OK]

원격 조작 실행

  1. 노드 기기 전원 ON
  2. WIRES-X 소프트웨어 실행
  3. 원격 조작용 PC 부팅
  4. 원격 모니터 소프트웨어 "WIRESMON-X.exe" 실행

사용법은 원격 모니터 소프트웨어의 온라인 도움말을 참조합니다.

18. 아날로그 음량 세부 조정

보통은 Preset Volume(12장)으로 충분하며, 필요하면 아래처럼 세밀하게 조정합니다. 아날로그 모드에서만 가능하고, 디지털 노드 간 음성과 뉴스 기능 재생음은 조정할 수 없습니다.

노드를 아날로그 모드로

  1. WIRES-X 소프트웨어 실행
  2. "File" 메뉴 → "Transceiver"
  3. "Operation mode"에서 "Analog" 선택
  4. [OK]

파형 모니터 보는 법

"View" → "Audio adjustment" 창의 "Audio" 영역에 음성이 파형으로 표시됩니다.

  • 실선: HRI-200이 받을 수 있는 최대·최소 음량
  • 점선: 이상적인 최대·최소 음량 범위
  • "Volume" 영역의 색 막대: 현재 입력·출력 음량

입력 음량 조정 (MIC LEVEL)

  1. "View" → "Audio adjustment"
  2. "Graph select"의 [Start] 클릭 (→ [Displaying]으로 바뀜)
  3. 레벨이 맞춰진 다른 FM 무전기(FT3D, FT5D 등)에서 FM 모드로 DTMF #1 음을 송신
  4. "MIC LEVEL"의 [◄]/[►](또는 슬라이더)로 파형 진폭이 점선 안에 들어오게 조정

출력 음량 조정 (SP LEVEL)

  1. "View" → "Audio adjustment"
  2. "Graph select"의 [Start] 클릭
  3. 다른 FM 무전기에서 DTMF #1 음 송신
  4. 노드 무전기에서 입력음 크기를 확인
  5. "Test tone"의 [Start] 클릭 → 노드 무전기에서 테스트 톤 송신 (→ [Transmitting])
  6. "SP LEVEL"의 [◄]/[►]로 4단계에서 확인한 음량과 비슷하게, 찌그러짐·이상음이 없게 조정
  7. [Transmitting] 클릭 → 송신 정지

설정을 파일로 저장했다가 한꺼번에 불러올 수 있어 노드 PC 교체 시 유용합니다.

  • Export settings: 저장 위치와 파일명을 지정해 [Save] → 확장자 .wsv 파일 저장
  • Import settings: .wsv 파일 선택 → [Open] → 소프트웨어 재시작. 파일의 HRI-200 시리얼 번호·DTMF ID가 현재 등록 정보와 다르면 가져올 수 없음

File 메뉴 — 초기화·재인증

  • Set default: 설정 초기화. [OK]를 누르면 설정이 덮어써지고 소프트웨어가 종료됨
  • Retry activation: 사용자 정보 재인증. [OK] → 설정 삭제 후 종료 → 재시작하면 "WIRES ID Activation" 창이 떠서 9장의 절차로 다시 설정
참고소재지 등 서버에 등록한 사용자 정보가 바뀌면 WIRES-X 웹사이트에서 변경 신청을 한 뒤 재인증합니다.

File 메뉴 — 기타

  • Refresh list: 왼쪽 3개 창을 서버의 최신 정보로 갱신 (짧은 간격으로 반복하면 바뀌지 않을 수 있음)
  • IP Spec / Room Compatible: 12장, 15장 참조
  • Exit: 종료 (13장)
  • Settings: 왼쪽 트리에서 항목을 고르면 오른쪽에 설정 화면 표시. [OK] 저장 후 닫기 / [Cancel] 저장하지 않고 닫기. WIRES ID information·Location settings는 12장, Round QSO room settings는 15장, Transceiver는 11장 참조

23. 소프트웨어 제거

참고자동 시작을 선택해 설치했다면, 먼저 작업 표시줄의 WIRES-X 아이콘을 오른쪽 클릭해 "Quit"을 선택해 자동 재실행을 막습니다.
  1. WIRES-X 소프트웨어 종료
  2. Windows [Start] → [Settings]
  3. [Apps] → [Installed apps]
  4. 목록에서 WIRES-X를 찾아 […] 클릭
  5. [Uninstall] 클릭
  6. 다시 [Uninstall] 클릭
  7. "Automatically close applications and attempt to restart them after setup is complete" 선택

  9. 완료되면 설치된 앱 목록에서 WIRES-X가 사라짐
